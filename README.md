# Factorial Calculator

## Explanation

The Factorial Calculator calculates the factorial of a given non-negative integer.

## Problem Statement

Write a Python program to calculate `n!`, where the factorial of `n` is the product of all positive integers from 1 to `n`.

## Features

* Calculates factorial
* Handles zero correctly
* Validates negative input
* Uses an iterative approach

## How It Works

1. Read a non-negative integer.
2. Start the result with 1.
3. Multiply the result by each number from 1 to `n`.
4. Display the factorial.

## Technologies Used

* Conditional Statements

## Data Structure Used

## Sample Input

```text
Enter a number: 5
```

## Sample Output

```text

```
